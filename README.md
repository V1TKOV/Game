# NEON SNAKE

Адаптивная браузерная «Змейка» на HTML, CSS и JavaScript, без библиотек и сборки.

## Запуск

Откройте `index.html` в браузере. Или запустите `python3 -m http.server 8080` в папке проекта и откройте http://localhost:8080.

## Управление

- Стрелки / WASD — поворот.
- Пробел или кнопка паузы — пауза и продолжение.
- На телефоне — экранные кнопки или свайпы по полю.
- Еда приносит 10 очков. Каждые 30 очков скорость растёт.
- Столкновение со стеной или собой завершает игру.
- Рекорд сохраняется локально в браузере, если хранилище доступно.

## GitHub Pages

После загрузки в репозиторий откройте Settings → Pages → Deploy from a branch, выберите ветку `main` и папку `/ (root)`, нажмите Save. GitHub покажет адрес опубликованной игры. Для приватного репозитория доступность Pages зависит от тарифа GitHub.
