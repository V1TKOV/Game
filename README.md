# Импульс — неоновая арена

Браузерная игра на выживание: пять волн противников, автоматическая стрельба, рывок с защитой от урона, энергия и выбор улучшений. На пятой волне появляется босс с круговыми залпами. После победы начисляется бонус за скорость. Рекорд сохраняется в браузере.

## Запуск

Нужен только статический сервер, сборки нет:

```sh
npm start
```

Откройте http://localhost:8080. Для запуска нужен Python 3. Можно использовать любой другой статический сервер. Игра работает на GitHub Pages из корня репозитория. Если Pages настроен на `main / (root)`, новая версия появится после слияния pull request в main.

## Управление

- WASD или стрелки — движение. Корабль стреляет по ближайшему противнику автоматически.
- Пробел — рывок. Восстановление занимает две секунды.
- P, Escape или кнопка над ареной — пауза.
- На сенсорном экране — джойстик слева и кнопка рывка справа.
- Голубые кристаллы дают энергию. При повышении уровня выберите одно из трёх случайных усилений.
- Звук включается отдельной кнопкой, по умолчанию выключен.

При потере фокуса или сворачивании страницы игра ставится на паузу. Поддерживается системная настройка уменьшения движения. Нет загрузки моделей, игровых ассетов, камеры или регистрации. Google Fonts используются только для оформления; доступны системные шрифты на случай отсутствия сети.

## Проверка

```sh
npm ci
npm test
```

Проверки движка покрывают движение, границы арены, рывок, паузу, улучшения, проигрыш и победу над боссом.

Для браузерной проверки при запущенном сервере:

```sh
node tests/browser.mjs
```

Скрипт использует Chromium по пути `/usr/bin/chromium` и проверяет компьютерный и сенсорный режимы, управление, паузу, отсутствие ошибок JavaScript и горизонтальной прокрутки. Снимки сохраняются в `artifacts/`.

## Структура

- `engine.js` — игровой мир, урон, противники, волны и улучшения.
- `game.js` — Canvas, ввод, меню, звук и локальный рекорд.
- `index.html`, `style.css` — адаптивная оболочка.
- `studio/` — сохранённая предыдущая студия «Эфир», доступная по ссылке в шапке игры. Камера и внешние модели нужны только самой студии.
