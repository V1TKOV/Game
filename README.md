# Аномалия — охотник за существами

Браузерная игра с настоящим распознаванием руки через MediaPipe Hand Landmarker. Светящиеся существа появляются поверх зеркального изображения фронтальной камеры. Это экранная игра с камерой, без распознавания геометрии комнаты и привязки объектов к стенам.

## Запуск на GitHub Pages

Замените старые файлы игры в корне репозитория: `index.html`, `style.css`, `game.js`, `README.md`. Добавьте `engine.js` рядом с ними. В Settings → Pages выберите Deploy from a branch → main → / (root) → Save. Откройте HTTPS-адрес, который покажет GitHub Pages.

Для локального запуска: `python3 -m http.server 8080`, затем http://localhost:8080. Открытие HTML двойным щелчком не поддерживается: используются ES-модули, а камере нужен защищённый контекст. На телефоне используйте HTTPS-адрес Pages, а не HTTP-адрес компьютера в локальной сети.

## Как играть

1. Откройте сайт в актуальном Safari или Chrome. Нажмите «Включить камеру» и разрешите доступ.
2. Поставьте телефон на опору, покажите одну ладонь целиком при хорошем свете. Используется фронтальная камера. Не закрывайте пальцы другой рукой.
3. Круг следует за кончиком указательного пальца. Наведите его на существо, соедините большой и указательный пальцы и удерживайте до заполнения кольца.
4. Разомкните пальцы перед следующей поимкой. Если рука пропадёт из кадра, таймер остановится, а незавершённый захват сбросится.
5. Экспедиция длится 60 секунд распознаваемого игрового времени. После каждых пяти поимок уровень растёт. Искра даёт 100 очков, Беглец — 180, Призрак — 300. Рекорд хранится в браузере.

«Сначала попробовать без камеры» запускает ту же игру с управлением мышью или касанием: нажмите на существо и удерживайте. Также работают стрелки и удержание пробела при фокусе на поле. Рекорд общий для обоих режимов.

Кнопка «Пауза» останавливает игру; камера остаётся включённой. «Выйти», окончание раунда и уход со страницы освобождают камеру. При сворачивании вкладки игра ставится на паузу. Звук включается отдельно.

## Камера и зависимости

Видео и точки руки обрабатываются локально в браузере; приложение не записывает и не отправляет кадры. При первом запуске камера-режима браузер скачивает MediaPipe Tasks Vision **0.10.21** с jsDelivr и модель Hand Landmarker с Google Storage. Для этого нужен интернет. Внешние сервисы получают обычные запросы загрузки файлов (включая IP-адрес), но не видео. Пробный режим не загружает модель и не запрашивает камеру.

Если доступ запрещён, разрешите камеру в настройках сайта. Если модель не загружается, проверьте интернет и блокировщики CDN. Встроенные браузеры мессенджеров могут ограничивать камеру — откройте страницу в Safari/Chrome. Скорость распознавания зависит от устройства.

## Проверки

`npm test` проверяет захват, потерю руки, таймер, уровни и координаты зеркальной камеры. Файлы из `tests/` не нужны для публикации.
